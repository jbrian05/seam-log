# Seam Log

A small offline web app for sewing: body measurements with history, fit profiles that work out finished-garment sizes, and a log of projects and alterations.

Everything is stored on the device (IndexedDB). Nothing is sent to a server. Use **More → Export backup** to keep a copy.

Plain HTML/CSS/JS, no build step. To run locally: `python3 -m http.server` in this folder.
